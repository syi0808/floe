# 스케줄링 사양

## 목적

사용자 캘린더 관리 : 이벤트 작성, 업데이트 및 삭제;최적의 시간을 추천합니다.갈등을 감지합니다.여러 달력 소스에서 간결한 일정 요약을 생성합니다.

## 통합

* Google Calendar API (OAUTH, 푸시 알림)
* Microsoft 그래프 캘린더
* 로컬 ICIC (.ICS) 가져 오기/내보내기

## 기술

|기술 |args |반환 |
|------------------ |---------------------------------------------------------------------------- |---------------- |
|`create_event` |`제목 ',`start',`end ',`참석자?`,`location?`|`eventId` |
|`update_event` |`eventId`,`패치 '|`event` |
|`proply_` |`duration`,`window ',`기본 설정?`|`슬롯 []`|
|`detect_conflict` |`start`,`end` |`충돌 []`|
|`summarize_schedule` |`period` (` "오늘"\ | ISO 날짜 범위),`granularity?`(`daily`/`weekly`) |`마크 다운`요약 |

## 시간 검색 알고리즘

1. 모든 연결된 캘린더에서 바쁜 블록을 병합하십시오.
2. 사용자 기본 설정 (작업 시간, 포커스 블록)을 적용하십시오.
3. 기대, 맥락 적 중요성 및 충족 밀도에 따른 후보자 슬롯.

## 스케줄 요약 생성

1. '기간'내에서 이벤트를 수집하십시오.
2. 매일 버킷, 우선 순위 (높은 중요성 이벤트).
3. 자유 시간 창을 포함한 출력 마크 다운 ≥ 1 시간.

## 성능 대상

* <400ms로 ≤ 20 슬롯 제안을 반환합니다.
* <300ms에서 매일 요약을 생성합니다.
* 외부 변경에 대한 Webhook 대기 시간 <5 s.

## 엣지 케이스

* 위치 변경시 시간대 이동 → 자동 계산.
* 하루 종일 대 멀티 며칠 이벤트가 별도로 처리됩니다.

## 예제 호출

```JSONC
// 45 분 슬롯을 제안합니다
{
"에이전트": "스케줄링",
"기술": "제안 _time",
"Args": { "duration": "pt45m", "창": "2025-05-14/2025-05-18"}
}

// 오늘의 개요를 얻습니다
{
"에이전트": "스케줄링",
"기술": "Summarize_Schedule",
"Args": { "기간": "오늘"}
}
```
