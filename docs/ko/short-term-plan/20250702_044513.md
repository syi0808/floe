## 1. 문제 설명

환경 설정 지침에서 `pip install -r requirements.txt` 명령을 직접 실행해야 합니다. 이를 간소화하기 위한 스크립트를 추가하고 문서에 반영합니다.

## 2. 입력 맥락

* **파일/모듈**: `requirements.txt`
* **문서**: `docs/environment_notes.md`, `docs/ko/environment_notes.md`

## 3. 기대 결과 / 성공 기준

| # | 성공 조건 | 검증 방법 |
| - | -------- | -------- |
| 1 | `scripts/setup_env.sh`가 의존성 설치 | 스크립트 실행 확인 |
| 2 | 영어 및 한글 문서 업데이트 | 마크다운 검토 |
| 3 | 단기 계획에서 스크립트 언급 | 계획 파일 존재 |

## 4. 제약 사항

* 스크립트는 단순하고 POSIX 호환이어야 합니다.

## 5. 단계별 절차 (AI용)

1. `pip install -r requirements.txt` 명령을 담은 `scripts/setup_env.sh` 작성
2. 환경 노트 문서를 업데이트하여 스크립트 사용을 안내
3. `pytest` 실행하여 회귀 여부 확인
4. 작업 내용을 기록 문서에 남김

## 6. 코드 스켈레톤

```bash
#!/bin/bash
set -e
pip install -r requirements.txt
```

## 7. 테스트 / 검증

```bash
pytest -q
```
