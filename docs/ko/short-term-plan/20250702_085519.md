## 1. 문제 진술

HTTP를 통해 OrchestrationEngine과 상호작용하는 FastAPI 기반 UI 패키지를 추가합니다.

## 2. 입력 컨텍스트

* **파일/모듈**: 새 `floe_ui/` 패키지, `README.md`

## 3. 기대 결과 / 성공 기준

| # | 성공 조건 | 검증 방법 |
| - | --- | --- |
| 1 | `OrchestrationEngine`을 호출하는 `/query` 엔드포인트 노출 | 수동 curl |
| 2 | 간단한 HTML 프론트엔드가 해당 엔드포인트로 요청 전송 | 수동 테스트 |
| 3 | README에 UI 실행 방법 명시 | 문서 확인 |

## 4. 제약 사항

* 프론트엔드는 최소한으로 유지 (순수 HTML + fetch)
* 코어 엔진 변경 없이 기존 로직 재사용

## 5. 단계별 계획

1. `floe_ui` 패키지에 `main.py`, `server.py`, `templates/index.html` 생성
2. CLI와 유사하게 `OrchestrationEngine` 인스턴스화
3. `text`와 `user_id`를 받는 `/query` POST 라우트 구현
4. 테스트용으로 루트에서 정적 HTML 제공
5. `requirements.txt`에 `fastapi`, `uvicorn` 추가
6. `README.md`에 사용 방법 문서화
7. `pytest` 실행 (의존성 문제로 실패 예상)

## 6. 코드 스켈레톤

```python
# floe_ui/server.py
from fastapi import FastAPI
from orchestrator_agent.orchestrator_core import OrchestrationEngine

app = FastAPI()
engine = OrchestrationEngine()

@app.post("/query")
async def query(text: str, user_id: str):
    intent = extract_intent_and_entities(text)
    return engine.route_request(intent, user_id)
```
