## 1. 문제 설명

InsightGenerator의 캐시가 무한히 커지지 않도록 크기 제한 기능을 추가한다.

## 2. 입력 맥락

* **파일/모듈**: `insight_agent/insight_generator.py`
* **테스트**: `tests/insight_agent/test_insight_generator.py`

## 3. 기대 결과 / 성공 기준

| # | 성공 조건 | 검증 방법 |
| - | ----- | -------- |
| 1 | flush 후 캐시 항목이 max_entries 이하로 유지됨 | pytest |
| 2 | 제한을 초과하면 오래된 항목이 제거됨 | pytest |

## 4. 제약 사항

* 표준 라이브러리만 사용
* max_entries가 None이면 기존 동작 유지

## 5. 단계별 계획

1. `InsightGenerator.__init__`에 선택적 `max_entries` 인자를 추가한다.
2. `_flush_cache` 시 삽입 순서를 기준으로 최신 항목 `max_entries`개만 남긴다.
3. 메모리와 디스크 캐시 모두 잘라내기를 적용한다.
4. 캐시가 증가하고 정리되는지 검증하는 테스트를 작성한다.
5. 기능 완료 후 영문/한글 기록을 남기고 `pytest`를 실행한다.

## 7. 테스트 / 확인 항목

```python
ig = InsightGenerator(max_entries=2)
ig.compile({"a": []})
ig.compile({"b": []})
ig.compile({"c": []})
assert len(ig._cache) == 2
```
