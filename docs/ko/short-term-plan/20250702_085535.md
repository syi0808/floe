HTTP 요청을 모킹하여 클라이언트 메서드와 다중 에이전트 상황에서의 호출을
확인하는 테스트를 추가해야 한다.

## 2. 입력 맥락

* **파일/모듈**: `mcp/client.py`
* **테스트**: `tests/mcp`, `tests/integration`

| 1 | `MCPClient.add_memory`와 `search_memories`가 HTTP 응답을 올바르게 처리 | pytest |

3. 여러 에이전트가 동일한 `MCPClient`를 사용하도록 하여 호출 여부를 검증한다.
4. `pytest`를 실행하고 결과를 커밋한다.
