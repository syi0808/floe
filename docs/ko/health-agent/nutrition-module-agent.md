# NutritionModuleAgent 사양

## 목적

식사 및 영양소 섭취량을 추적하고,식이 품질을 평가하며, 맞춤형 영양 알림 또는 조정을 제공하십시오.

## 데이터 입력

* 기록 된 식사 (사진, 텍스트 또는 바코드 스캔).
* 잔액 계산을위한 웨어러블 유래 칼로리 소비.

## 기술

|기술 |args |반환 |
|--------------- |---------------------------------- |---------------- |
|`log_meal` |`description`,`timestamp`,`영양소?`|`ealid` |
|`Analyze_intake` |`Window` |`macro_breakdown` |
|`proply_meal` |`GOOR ',`DIETARY_RESTRICTIONS?`|`식사 _plan` |

## 알고리즘

* 매크로 추정을위한 USDA FoodData 조회.
* 사용자 목표 (유지 보수, 벌크, 컷)와 비교하는 7 일 평균 롤링.

## 알림

* 아래의 단백질 섭취는 2 일 → 프롬프트 고 단백질 레시피를 목표로합니다.
* 3 시간 금식 창이 낮에는 초과 → 부드러운 식사 알림.

## 개인 정보

* 국부적으로 분석 된 이미지;클라우드 비전 업로드가 없습니다.
* 휴식시 암호화 된 음식 통나무.
