# WellnessModuleAgent 사양

## 목적

스트레스, 기분 및 전반적인 복지를 모니터링하여 번 아웃의 초기 징후를 감지하고 회복 또는 마음 챙김 활동을 권장합니다.

## 데이터 입력

* 웨어러블의 심장 박동 변동 (HRV) 트렌드.
* 자체보고 된 기분 체크인 (1–5 스케일).
* 작업 및 일정 에이전트의 작업량 데이터 (작업 수, 회의 시간).

## 기술

|기술 |args |반환 |
|------------------ |-------------------------- |----------------------------- |
|`log_mood` |`평가`,`timestamp`,`note?`|`eptyId` |
|`평가_stress` |`Window` |`Stress_Level` (낮은/med/High) |
|`추천 _recovery` |`context` |`활동`|

## 스트레스 평가 규칙

```
Stress_Score = (Workload_Z + HRV_Z_INV + mood_inv) / 3
```

* 높음> 0.7;중간 0.4–0.7;낮은 <0.4.

## 복구 제안

|트리거 |추천 |
|-------------------------- |--------------------------------------- |
|높은 스트레스 |10 분의 호흡 운동 + 블록 "초점 시간"|
|연속 높은 스트레스 3days |하루 쉬고 조명 운동을 제안합니다 |

## 개인 정보

* 분위기 통나무 암호화;사용자는 N 일 후에 자동 변형을 설정할 수 있습니다.
