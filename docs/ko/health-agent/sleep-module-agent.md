# sleepModuleAgent 사양

## 목적

HealthAgent 및 Insightagent에 대한 야간 수면 단계, 회복 점수 계산 및 표면 통찰력을 분석하십시오.

## 입력

* 웨어러블의 수면 세션 (시작, 끝, 무대 분석).
* 사용자의 주관적인 수면 품질 등급 (1-5).

## 출력

*`sleep_score` (0-100) 기간, 효율, rem/deep %에 의해 가중치.
*`sleep_debt '분.

## 기술

|기술 |args |반환 |
|------------------------------------- |------------- |
|`Analyze_sleep` |`세션`|`sleepmetrics` |
|`추천 _bedtime` |`NextDaysCheDule` |`취침 시간 '|

## 알고리즘

* 2 박 롤링 기준선.
* 이전 데이터의 지수 붕괴.

## 알림

* 수면이면 \ _debt> 120 분 → 대화 이벤트를 통해 초기 취침을 제안하십시오.
