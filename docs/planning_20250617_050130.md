## Next Steps for TaskAgent

The next phase for `TaskAgent` development will focus on implementing the core task management logic within `task_agent/task_core.py`, as specified in section 3.5.2 of `docs/implementation_plan.md`.

Key functionalities for `task_core.py` will include:
-   **`TaskItem` Data Structure**: Defining a Pydantic model for `TaskItem` (including fields like `id`, `user_id`, `description`, `created_at`, `due_date_utc`, `completed_at`, `priority`, `status`, `project_tags`, `linked_schedule_id`).
-   **Storage**: Initial implementation will use in-memory storage (e.g., a dictionary). Future iterations will integrate with `MemoryManagerAgent` and/or a dedicated task database via MCP.
-   **CRUD Operations**: Implementing functions for `create_task`, `get_task`, `update_task` (for status, due date, etc.), `delete_task`, and `list_tasks` (with filtering capabilities).
-   **Priority Calculation**: Basic logic for determining task priority, potentially based on due dates and explicit user input.
-   **Reminders**: Placeholder for future reminder logic (actual reminder triggering will likely involve MCP or a scheduler).
