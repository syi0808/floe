# Progress History

This directory keeps completed implementation increments and superseded checkpoints out of the
current [`PROGRESS.md`](../../PROGRESS.md) dashboard. These records describe what was known at the
time; current acceptance status always comes from `PROGRESS.md` and the canonical validation record
for the active slice.

## Maintenance

- Add a dated or bounded-period file when completed increments would make `PROGRESS.md` harder to scan.
- Preserve validation detail in `docs/validation/` and link to it from the history record.
- State acceptance as it was at the checkpoint and label superseded conclusions explicitly.
- Do not treat a historical test count or remaining-work list as current status.
