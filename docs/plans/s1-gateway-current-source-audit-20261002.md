## Additional closure in the same checkpoint

- `TursoStore::open_existing` requires a real supported SQLite profile, validates the exact schema through a read-only engine and never calls initialization. A custom IO adapter pins a main file opened without Create; the high-level Builder's default cannot recreate a missing selected profile. The explicit creator retains initialization, including the source-operation table and unique active-source fence. The supported source-schema marker is required on reopen; older/other schemas fail closed.
- Source reservations and Access committed/aborted receipts bind the caller device in addition to Person, command, operation, reservation, generation and original source authority. Command replay precedes fresh source admission. A missing receipt remains unresolved; it is not an abort proof.
- Native configuration requires a durable Access InvalidateSource receipt before the source successor CAS. It pauses and marks every non-revoked grant for review, advances grant authority and invalidates derived state; selecting more source resources cannot silently expand a live grant. Generic cancellation cannot complete a configured source without its encrypted, reviewed successor.
- Native permission setup creates a Pending source before an explicit RequestPermission operation. Product start returns immediately after durable admission. An already-dispatched prompt found after restart becomes RepairRequired; it is not opened a second time. A Pending source exposes Configure only, because Observe and Disconnect require evidence that it does not yet have.
- Connections activation rejoins durable work and schedules a bounded catalog refresh. An offline Gateway does not prevent local Vault unlock. Remote catalog errors remain owner failures, with unavailable cached integration capabilities; they are not interpreted as model absence. Product get/overview calls do not drive recovery.
- Lost hosted integration start responses rejoin the same persisted operation, original catalog revision and scope. Confirmed remote NotFound permits only that exact idempotent start command. The Gateway retains OAuth state, provider URLs/codes and secrets in its operator UI.
- Observe-review disclosure is projected from immutable `ReviewedView.current_processing`, not from a newly loaded grant snapshot.

## Accepted contract corrections

`IntegrationReview.target` is a closed tagged union: Device { device_id } or Gateway { gateway_ref, gateway_revision }. NativePermission requires Device; other setup kinds require Gateway. No fabricated Gateway identity is used for native setup.

Every currently supported completed ConnectionOperationSnapshot carries the actual SourceSummary. Gateway forgetting has its own GatewaySummary result and does not invent a completed source operation.

Remote resource configuration remains Gateway-managed in S1 because there is no complete remote resource catalog. The current selected resources are not presented as a complete inventory. Lossless multi-source Day mirroring remains S2; the signed normalized model-source path remains S1.
