## Common wire decisions

These are mechanical bounded wire representations of already frozen safe owner types, not new domain design. No owner-crate dependencies, serde_json::Value escape hatch, raw authority records or transparent owner serialization. Fields retain the exact snake_case names and closed enum tags from owner declarations; append Dto to type names. UUID values use existing UuidRefDto or existing typed refs where the semantic type matches. SHA256 fields use DigestHex64Dto, not arrays; revisions/counts remain bounded nonnegative numeric values. UTC instants are RFC3339 strings; civil dates YYYY-MM-DD. Reject unknown fields. Export public validate() methods for aggregate request/result shapes; callers will invoke these after decode. Nested validators must validate IDs, digest shape, positive revisions and bounded collections/text without inventing permissions or recomputing authority. Reuse existing common DTOs where exact semantics match; report needed exports. Do not add tests in S2.
