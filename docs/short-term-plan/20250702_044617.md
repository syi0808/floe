## 1. Problem Statement

Add cache pruning capability to InsightGenerator so disk cache does not grow indefinitely.

## 2. Input Context

* **파일/모듈**: `insight_agent/insight_generator.py`
* **테스트**: `tests/insight_agent/test_insight_generator.py`

## 3. Expected Output / Success Criteria

| # | 성공 조건 | 검증 방법 |
| - | ----- | -------- |
| 1 | Cache entries limited to max_entries after flush | pytest |
| 2 | Old entries pruned when new ones exceed limit | pytest |

## 4. Constraints

* Use only standard libraries
* Maintain backward compatibility if max_entries is None

## 5. Step-by-Step Outline (for AI)

1. Add optional `max_entries` argument to `InsightGenerator.__init__` storing limit.
2. On `_flush_cache`, sort entries by insertion order and retain newest `max_entries`.
3. Ensure `_cache` respects trimming both in memory and on disk.
4. Write tests verifying cache grows then prunes correctly.
5. Document feature in records (en/ko) after implementation and run `pytest`.

## 7. Tests / Assertions

```python
# create generator with small limit
ig = InsightGenerator(max_entries=2)
ig.compile({"a": []})
ig.compile({"b": []})
ig.compile({"c": []})
assert len(ig._cache) == 2
```
