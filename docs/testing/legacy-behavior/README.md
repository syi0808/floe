# Legacy behavior evidence

These are natural-language records extracted before the old tests were removed. They preserve behavior, failure and recovery cases for current test reconstruction. They are historical source evidence, not claims that the old suite passed, that the current implementation is correct, or that every old assertion is still a requirement.
