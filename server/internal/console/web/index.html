02 · Add or update a target

Bring your own model

For an unchanged provider and endpoint, a blank key keeps the current key. A changed endpoint never inherits it. To remove a key, delete the target and recreate it.

03 · Performance classes

Choose server-side defaults

Floe requests only a performance class. The server resolves it to a target and reasoning effort, so provider changes never require app configuration.

04 · Subscription authentication

Connect with Codex / ChatGPT

Floe runs the browser OAuth flow directly, keeps access and refresh tokens in macOS Keychain, and uses them only inside this Go server. Existing Codex CLI logins are not imported.

Codex requests use the ChatGPT Codex backend and may consume subscription limits. External context still requires approval in Floe.
